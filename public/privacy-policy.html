Privacy Policy for MoyennesED

Last updated: December 03, 2023

This privacy policy governs your use of the software application MoyennesED (“Application”) for mobile devices. The Application does not collect any user data. However, it does use third-party services that may collect information used to identify you.

Google AdMob

The Application uses Google AdMob for advertising. Google AdMob is an advertising service provided by Google Inc. You can read Google’s privacy policy here

Data Collected by Google AdMob

The Google Mobile Ads SDK collects and shares the following data types automatically for advertising, analytics, and fraud prevention purposes :

  • IP address: The SDK collects the device’s IP address, which may be used to estimate the general location of a device.

  • User product interactions: The SDK collects user product interactions and interaction information, including app launch, taps, and video views.

  • Diagnostic information: The SDK collects information related to the performance of your app and the SDK, including crash logs, app launch time, hang rate, and energy usage.

  • Device and Account identifiers: The SDK collects Android advertising (ad) ID, app set ID, and, if applicable, other identifiers related to signed-in accounts on the device.

All of the user data collected by Google Mobile Ads SDK is encrypted in transit using the Transport Layer Security (TLS) protocol

Data Handling

Android ad ID collection is optional. The ad ID can be reset or deleted by users using ad ID controls in the Android settings menu.
